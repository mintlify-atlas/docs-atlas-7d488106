Hyprland is a dynamic tiling Wayland compositor that gives you full control over your desktop through a Lua-based configuration system. It features smooth animations, multiple tiling layouts, a powerful keybind engine, and an extensible plugin architecture — all while running natively on Wayland.

## Quick Start

<Steps>
  <Step title="Install Hyprland">
    Install from your distro's package manager. On Arch: `sudo pacman -S hyprland`. On NixOS, enable `programs.hyprland.enable = true;`.
  </Step>
  <Step title="Launch Hyprland">
    Start a session from your login manager or TTY by running `Hyprland`. A default config is created at `~/.config/hypr/hyprland.lua`.
  </Step>
  <Step title="Configure with Lua">
    Edit `~/.config/hypr/hyprland.lua` to set options, keybinds, and rules using the `hl.*` API.
    ```lua
    hl.config({ general = { gaps_in = 5, gaps_out = 10, border_size = 2 } })
    hl.bind("SUPER + Return", hl.dsp.exec_cmd("foot"))
    hl.bind("SUPER + Q", hl.dsp.window.close())
    ```
  </Step>
  <Step title="Explore the Wiki">
    Read the [Master Tutorial](/getting-started/master-tutorial) for a complete walkthrough, then explore the sidebar for monitors, rules, animations, and the full Hypr* ecosystem.
  </Step>
</Steps>

<Note>
  Hyprland is not a full Desktop Environment — it is a compositor that you build your desktop around. Apps, status bars, wallpapers, and lock screens are your choice to install and configure. See [Useful Utilities](/useful-utilities) for recommended tools.
</Note>
