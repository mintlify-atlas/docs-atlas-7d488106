Hyprland has first-class support for the Nix ecosystem. Whether you are running NixOS, a traditional Linux distribution with the Nix package manager installed alongside it, or looking to manage your Hyprland configuration declaratively, this section covers everything you need. One of the key advantages of using Hyprland through Nix is that it eliminates the `.so` shared-library version mismatches that can cause crashes on conventional distributions — Nix ensures that Hyprland and all of its dependencies are built against exactly the same library versions.

## Why Use Nix for Hyprland?

On conventional distributions, keeping Hyprland and its runtime dependencies — `wayland`, `mesa`, `libinput`, `xdg-desktop-portal-hyprland`, and others — perfectly in sync is the user's responsibility. A single library upgrade can silently break Hyprland with a cryptic `.so` version error.

Nix solves this by pinning every dependency in the package graph to exact, reproducible versions. When you install Hyprland through Nix or NixOS, every library it links against is guaranteed to be present at the correct version in the Nix store, regardless of what else is installed on the system.

## Choosing the Right Installation Method

<Tabs>
  <Tab title="NixOS (Recommended)">
    If you are already running NixOS, enabling Hyprland takes a single line in your `configuration.nix`. The NixOS module sets up the session file, the XDG portal, and all required system-level configuration automatically.

    ```nix
    {
      programs.hyprland.enable = true;
    }
    ```

    See the [NixOS page](/nix/nixos) for the full guide, including flake usage and the binary cache.
  </Tab>
  <Tab title="Nix on Another Distro">
    If you are on Ubuntu, Fedora, Arch, or any other distribution, you can install the Nix package manager and then run Hyprland from the Nix store. This gives you an always-up-to-date Hyprland without needing to compile anything or depend on your distro's packaging.

    Install Hyprland via the flake:

    ```sh
    sudo nix profile add --profile /nix/var/nix/profiles/default github:hyprwm/Hyprland
    ```

    See the [Any Distro page](/nix/nixos) for details on `nixGL` and login manager integration.
  </Tab>
</Tabs>
