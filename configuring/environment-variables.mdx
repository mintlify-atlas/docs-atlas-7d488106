Hyprland exposes a simple `hl.env()` function for setting environment variables before the display server initialises. This is the recommended way to configure your Wayland session's environment rather than adding Wayland-specific variables to system-wide files like `/etc/environment`.

```lua
hl.env("GTK_THEME", "Nord")
```

<Warning>
Avoid placing Wayland-specific environment variables in `/etc/environment`. On traditional distributions, doing so will cause all sessions — including Xorg ones — to pick them up, likely breaking those sessions.
</Warning>

<Note>
When referencing existing environment variables, use `os.getenv()` rather than shell expansion. For example:

```lua
hl.env("SSH_AUTH_SOCK", os.getenv("XDG_RUNTIME_DIR") .. "/ssh-agent.socket")
```
</Note>

## Hyprland Variables

These control Hyprland's own runtime behaviour.

```lua
hl.env("HYPRLAND_TRACE", "1")        -- Enable more verbose logging
hl.env("HYPRLAND_NO_RT", "1")        -- Disable realtime priority setting
hl.env("HYPRLAND_NO_SD_NOTIFY", "1") -- Disable sd_notify calls (systemd)
hl.env("HYPRLAND_NO_SD_VARS", "1")   -- Disable systemd/D-Bus activation env management
hl.env("HYPRLAND_CONFIG", "/path/to/hyprland.lua") -- Custom config path
```

## Aquamarine (GPU Backend)

These control [Aquamarine](https://github.com/hyprwm/aquamarine), Hyprland's rendering backend.

```lua
hl.env("AQ_TRACE", "1")              -- Enable trace-level logging (very verbose)
hl.env("AQ_DRM_DEVICES", "/dev/dri/card1:/dev/dri/card0") -- Explicit GPU list (colon-separated)
hl.env("AQ_FORCE_LINEAR_BLIT", "0")  -- Disable forced linear modifiers (may help NVIDIA)
hl.env("AQ_MGPU_NO_EXPLICIT", "1")   -- Disable explicit fences for multi-GPU scanout
hl.env("AQ_NO_MODIFIERS", "1")       -- Disable modifiers for DRM buffers
hl.env("AQ_NO_KMS_REQUIREMENT", "1") -- Disable KMS requirement for headless GPUs
hl.env("AQ_NO_ATOMIC", "1")          -- Disable atomic modesetting (HEAVILY NOT RECOMMENDED)
```

<Warning>
`AQ_NO_ATOMIC` is heavily discouraged. Only use it if you have a specific, well-understood reason.
</Warning>

## Mouse Cursor

Control cursor theme and size for both XCursor and Hyprcursor.

```lua
hl.env("XCURSOR_THEME", "MyCursorTheme") -- XCursor theme name
hl.env("XCURSOR_SIZE", "24")             -- XCursor size in pixels
hl.env("HYPRCURSOR_THEME", "MyHyprcursorTheme") -- Hyprcursor theme name
hl.env("HYPRCURSOR_SIZE", "24")          -- Hyprcursor size in pixels
```

<Tip>
The cursor theme must be installed and readable by your user. See the [hyprcursor page](https://wiki.hyprland.org/hypr-ecosystem/user/hyprcursor) for information on the native Hyprland cursor format.
</Tip>

## Qt Applications

```lua
hl.env("QT_QPA_PLATFORMTHEME", "qt6ct")        -- Pick theme from qt6ct
hl.env("QT_AUTO_SCREEN_SCALE_FACTOR", "1")     -- Enable automatic DPI scaling
hl.env("QT_WAYLAND_DISABLE_WINDOWDECORATION", "1") -- Disable Qt window decorations
```

## GTK Applications

```lua
hl.env("GTK_THEME", "yourVeryPrettyTheme") -- Set GTK theme manually
```

## GUI Toolkit Backends

These tell toolkits which windowing backend to use, with Wayland preferred and X11 as fallback.

<CodeGroup>

```lua GTK (GDK)
hl.env("GDK_BACKEND", "wayland,x11,*")
-- Use Wayland if available, fall back to X11, then any other backend
```

```lua Qt
hl.env("QT_QPA_PLATFORM", "wayland;xcb")
-- Use Wayland, fall back to X11 (xcb)
```

```lua SDL2
hl.env("SDL_VIDEODRIVER", "wayland")
-- Run SDL2 apps on Wayland. Set to "x11" for older games with SDL compatibility issues
```

```lua Clutter
hl.env("CLUTTER_BACKEND", "wayland")
-- Force Clutter applications onto the Wayland backend
```

</CodeGroup>

## Complete Example

A realistic environment setup for a Wayland session:

```lua
-- Wayland backends
hl.env("GDK_BACKEND", "wayland,x11,*")
hl.env("QT_QPA_PLATFORM", "wayland;xcb")
hl.env("SDL_VIDEODRIVER", "wayland")
hl.env("CLUTTER_BACKEND", "wayland")

-- Qt theming
hl.env("QT_QPA_PLATFORMTHEME", "qt6ct")
hl.env("QT_AUTO_SCREEN_SCALE_FACTOR", "1")
hl.env("QT_WAYLAND_DISABLE_WINDOWDECORATION", "1")

-- Cursor
hl.env("XCURSOR_THEME", "Adwaita")
hl.env("XCURSOR_SIZE", "24")
hl.env("HYPRCURSOR_THEME", "Adwaita")
hl.env("HYPRCURSOR_SIZE", "24")
```
