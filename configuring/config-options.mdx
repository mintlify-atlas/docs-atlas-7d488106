Hyprland's configuration is driven by a Lua-based config file. Every option lives under a named category and is set using `hl.config()`. This page documents every option available across all core sections — excluding layout-specific options, which are described on their respective layout pages.

<Note>
Before continuing, familiarise yourself with the [naming conventions used in this wiki](/configuring/selectors). In particular, be aware of data types like `css_gaps`, `gradient`, `color`, and `vec2`.
</Note>

## Syntax

You can update many options at once:

```lua
hl.config({
  category1 = {
    option = value,
  },
  category2 = {
    option1 = value1,
    option2 = value2,
  },
})
```

Or only a few with dotted keys:

```lua
hl.config({ ["category.option"] = value })
```

Multiple `hl.config()` calls are allowed — each call only updates what was passed in. **If the same option is set multiple times, the last line wins.** You can also update options at runtime without touching your config file using `hyprctl eval 'hl.config(...)'`; those values revert to defaults on the next reload.

Opacity is a **product** of all opacities. Append `"override"` after a value to treat it as an absolute rather than a multiplier. For example, `opacity = "0.8 override 0.8 override 1.0 override"` sets active/inactive/fullscreen independently.
</Note>

<Accordion title="Blur variants">
Available `variant` values:

- `kawase` — default diffused blur
- `acrylic` — liquid glass-like effect
- `aurora` — aurora light streaks
- `drops` — rain on a window pane
- `fluid_jar` — 2D fluid simulation
- `frost` — cracked ice
- `haze` — pearlescent sheen
- `heat_shimmer` — subtle shimmer with chromatic aberration
- `prism` — triangular refraction mask
- `ripple` — ripple on click
- `water` — ripple via heightmap

Each variant may expose additional sub-options under `decoration.blur.<variant>`. Key ones include:

**`decoration.blur.acrylic`** — `aberration`, `bulb`, `clarity`, `refraction`, `tint`

**`decoration.blur.aurora`** — `color1`, `color2`, `intensity`, `speed`

**`decoration.blur.drops`** — `speed`

**`decoration.blur.fluid_jar`** — `color`, `distortion`, `fill_amount`, `mass`, `precision`, `speed`, `turbulence`

**`decoration.blur.glass`** (used by `aurora`, `drops`, `heat_shimmer`, `prism`) — `refraction`, `roughness`, `size`

**`decoration.blur.haze`** — `intensity`, `iridescence`

**`decoration.blur.heat_shimmer`** — `speed`

**`decoration.blur.ripple`** — `duration`, `radius`, `strength`, `width`

**`decoration.blur.water`** — `damping`, `duration`, `radius`, `speed`, `strength`
</Accordion>

<Accordion title="follow_mouse values">
- `0` — Cursor movement will not change focus.
- `1` — Cursor movement will always change focus to the window under the cursor.
- `2` — Cursor focus is detached from keyboard focus; clicking moves keyboard focus.
- `3` — Cursor focus is completely separate; clicking does not change keyboard focus.
</Accordion>
